# My Laravel Packages Demo App

I use this small Laravel application to test my packages in a real host app. It keeps hands-on UX and DX checks close to ordinary Laravel application code.

| Package | What it is for | Repository |
| --- | --- | --- |
| Laravel Timelines | Record deliberate application events and render prepared histories across Laravel interfaces. | [tehwave/laravel-timelines](https://github.com/tehwave/laravel-timelines) |
| Laravel Achievements | Add persistent, metadata-rich achievements to Eloquent models through a small Laravel-native API. | [tehwave/laravel-achievements](https://github.com/tehwave/laravel-achievements) |
| Laravel Shortcodes | Compile application-defined, WordPress-like shortcodes inside Laravel content. | [tehwave/laravel-shortcodes](https://github.com/tehwave/laravel-shortcodes) |
